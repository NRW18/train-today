# Equipment cutouts and source credits

Attribution for the retained unedited reference files is preserved in [ORIGINAL-PHOTOS.md](ORIGINAL-PHOTOS.md).

The default equipment cards use **AI-edited photographic-style cutouts**, not untouched photographs. People and backgrounds were removed, and occluded parts were reconstructed. Some apparatus details were generated; the shoulder-press example corrects the incline-press reference into an upright overhead press. Images are equipment examples, not technique demonstrations or exact product specifications. No author endorses KRYVOS.

All cutouts were made with the built-in image generation tool, with transparent output. Only resizing and WebP encoding were applied afterward; generated alpha is preserved. Shared apparatus reuse the same file: pec-deck/rear-delt, lateral-raise/curl, and pushup/plank (empty mat). Saved personal thumbnails still take priority and are never modified. Original photographic references remain in the parent directory for provenance, but are no longer cached as defaults.

Each derivative is distributed under the listed source license, including the same CC BY-SA version where applicable. Source pages contain full license notices. Licenses cover the individual images, not unrelated code. Source and author links are also available in Equipment → Photo credits. Prompt set: [CUTOUTS.md](CUTOUTS.md).
