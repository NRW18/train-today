สแกนเครื่องในยิม

ถ่ายรูปเครื่องทีละเครื่อง AI จะบอกว่าเป็นเครื่องอะไร เล่นท่าไหนได้ แล้วเพิ่มเข้าแอปให้

ใส่ Gemini API key (ฟรี ใส่ครั้งเดียว)

  1. เปิด aistudio.google.com/apikey แล้วล็อกอินด้วย Google
  2. กด Create API key แล้วคัดลอกมา
  3. วางในช่องข้างล่าง แล้วกดบันทึก

คีย์เก็บไว้ในเครื่องนี้เท่านั้น อย่าส่งคีย์ให้ใคร

ถ่ายให้เห็นทั้งเครื่อง เลี่ยงไม่ให้มีคนในภาพ รูปจะถูกส่งไปให้ Google Gemini วิเคราะห์ (แผนฟรี Google อาจนำไปปรับปรุงบริการ)

แอปนี้ตัดสินใจอย่างไร

  • กล้ามเนื้อที่เพิ่งฝึกยังไม่ถึง 48 ชั่วโมง จะยังไม่ถูกเลือกเป็นหลัก
  • เลือกวันที่กล้ามพร้อมที่สุด ถ้าพร้อมเท่ากันจะเรียงต่อ Push → Pull → Legs
  • เมื่อย: ตัดท่าที่ใช้ส่วนนั้นเป็นหลัก ส่วนท่าที่ใช้เป็นตัวช่วยจะลดเซ็ต
  • เจ็บ: ตัดทุกท่าที่โดนส่วนนั้นหรือข้อต่อนั้น และแสดงคำเตือน
  • น้ำหนัก: ทำครบ 12 ครั้งทุกเซ็ต ครั้งหน้าเพิ่ม 2.5 กก. ถ้าเหนื่อยจะไม่เพิ่ม
  • สแกนเครื่อง (AI): Gemini ดูรูปแล้วบอกว่าเป็นเครื่องอะไร ใช้กล้ามส่วนไหน โดนข้อต่อไหน แอปตรวจคำตอบก่อนใช้ และให้คุณยืนยันก่อนเพิ่มทุกครั้ง
